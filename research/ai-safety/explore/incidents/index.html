LLM-agent incident explorer

Real cases where a language model took actions (tool calls, code, browser, email, files) and caused or nearly caused harm. Each case is labelled for one question: could a rule written before deployment have blocked it?

What the labels mean
Writable in advance
Could a designer have written, before deployment, a concrete rule that a program can check on observable action features (tool name, command, target resource, recipient, amount, environment, approval token), not on intent or truth, and that would have blocked the harmful action? yes: such a rule blocks the harm. partial: it blocks the first-order harm but not the rest. no: the harm is open-world or depends on context: deception, injected instructions that look legitimate, misread intent.
Hindsight guard
The labelling prompt counts a rule only if it is generic to the deployment class, checkable at action time, plausible in a standard pre-deployment spec, and leaves the task feasible. A yes means a rule of that form exists. It does not mean someone would have written it or kept it switched on.
Approval gate
A step where a human must approve a specific action before it runs. Two things are shown. The catalog's own text for the gate, and a model label for the gate at the moment of harm: none, bypassed (the agent or attacker got around it, or the human approved on misleading information), disabled (the user had switched it off, for example skip-permissions or auto-approve), or worked partially.
Gate bypassed
A separate flag, set when a rule text or rationale says a gate, permission check, confirmation or safeguard existed but was disabled, bypassed, auto-approved or overridden by the user or operator. It is only set for rows that have a yes or partial rule.
Operator type
deployer-operated: a legitimate deployer, operator or user ran the agent, including when third-party injected content hijacked it. attacker-operated: the malicious party ran the agent as its own tool, so no deployer rule applies. unclear.
Two raters
S is Claude Sonnet, H is Claude Haiku, given the same prompt in separate calls. Where they differ the page marks the row with ≠. Statistics use Sonnet labels and leave out rows Sonnet vetoed as not an LLM agent taking actions, as the coverage report does.
