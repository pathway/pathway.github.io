    • LLM-judged labels. Every code was assigned by an LLM judge (claude-haiku-4-5-20251001; second rater claude-haiku-4-5-20251001 on D6 and D8 only). Agreement in Section 5 bounds reliability for D6/D8; D1-D5 and D7 have a single rater and no reliability estimate. Judges read the catalog row, not the primary sources.
    • Catalog selection bias. The incidents are those that were reported, verified, and chosen for the catalog; destructive coding-agent incidents and security PoCs are over-represented relative to quiet failures. Shares are shares of the catalog, not of deployed-agent failures.
    • Small N. N = 70. Wilson intervals are wide; crosstab cells are mostly 0 or 1. Treat every percentage as a direction, not an estimate.
    • Single primary label on D6. The RL-culture test asks for one class per incident; where the judge saw two McLean classes it had to choose, and its rationale in labels.json records the runner-up.
    • Codebook version. Codebook hash 82f3ff17e5a9. Labels are cached by incident id + this hash; a codebook change forces re-coding.
    • Calls. 28 claude CLI calls in the last run (43 cumulative for this codebook cache), 0 retries, 20 validation problems (see run_meta.json).
